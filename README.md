📊 Walmart-Sales-Analytics-and-Forecasting

📌 Project Overview

This project focuses on analyzing Walmart's retail sales data to uncover meaningful business insights and build predictive models for future sales forecasting.

The analysis helps understand how external factors such as unemployment, temperature, fuel prices, and CPI influence weekly sales across multiple stores. Additionally, the project identifies top-performing and underperforming stores and explores seasonal trends in sales.

🎯 Objectives

✅ Perform Exploratory Data Analysis (EDA) on retail sales data

✅ Identify relationships between sales and external factors

✅ Detect and handle missing values & outliers

✅ Analyze seasonal trends in sales

✅ Compare store performance

✅ Build a predictive model to forecast sales for the next 12 weeks


📂 Dataset Information

The dataset contains 6,435 records with the following features:

| Feature      | Description                  |
| ------------ | ---------------------------- |
| Store        | Store number                 |
| Date         | Week of sales                |
| Weekly_Sales | Sales for that week          |
| Holiday_Flag | Whether it is a holiday week |
| Temperature  | Temperature during the week  |
| Fuel_Price   | Fuel cost in the region      |
| CPI          | Consumer Price Index         |
| Unemployment | Unemployment rate            |
